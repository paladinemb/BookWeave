# BookWeave 2.1

应用位置：`/Applications/BookWeave.app`。中英文 PDF 均支持，文件在本机处理。

## 使用

选择 PDF，填写书名、作者和电子书语言，点击“开始／继续转换”。已有进度会自动复用，原始 PDF 不会修改。结果仍在“PDF转EPUB/转换结果”，每次保存到独立文件夹。

每段最多 300 页，并平均分配：1000 页分 4 段各 250 页，800 页分 3 段，1027 页分为 257、257、257、256 页。每段结束保存 part-*.md，全部完成后统一生成一个 EPUB。最终 content.md 含完整文字和图片引用。

## 继续与重试

可以停止后重新选择同一份 PDF，点击“开始／继续转换”，已完成页面无需重新 OCR。重新启动 App 或更换输出文件夹也能复用。若要重新识别异常页，勾选“重试待校对页”；已正常完成的页面继续复用。

PDF 内容改变后会建立新的缓存，不会误用旧文字。缓存保存在 `~/Library/Application Support/BookWeave/cache`，任务结果文件夹内的“任务状态.json”记录相应位置、已完成页数、分段范围及待校对页。

## 速度与资源

同一任务只加载一个 PaddleOCR-VL-1.6 官方 GGUF 模型。文字版页面直接提取；扫描页交给模型。一个独立进程提前准备下一页，队列最多两页，避免整本 PDF 同时驻留内存。正常图片保留原清晰度，不为提速统一降低分辨率。PNG 不重复优化压缩。

识别采用流式输出，发现明显的超长字符重复或循环段落会提前停止该页，保留原图并标记待校对。网络型本地服务异常最多重新启动重试一次，避免无止境卡住。

## 图片与已知限制

普通嵌入图片保留，页边位置的小面积、多页重复装饰会过滤；扫描页、复杂矢量图页保留原页图。文字可编辑，图片位于对应页文字之后，不保证原 PDF 的图文穿插位置。空白页保留空白页标记。

当前为整页 OCR，未集成完整版面分析流水线；复杂多栏、表格及密集小字需要人工校对。需校对页面清单在结果文件夹内。保存了原图不等于该页文字已经识别准确。
