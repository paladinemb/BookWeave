# BookWeave 2.4

应用位置：`/Applications/BookWeave.app`。中英文 PDF 均支持，文件在本机处理。

2.4 只对需要分段的大 PDF 开启并行：最多同时处理两个不同分段，共享一个识别引擎。300 页以内仍为单任务。继续保留 2.3.1 的精简资源和 2.3 的高清清边流程，已有高清缓存可复用。

## 使用

选择 PDF，填写书名、作者和电子书语言，点击“开始／继续转换”。已有进度会自动复用，原始 PDF 不会修改。结果仍在“PDF转EPUB/转换结果”，每次保存到独立文件夹。

每段最多 300 页，并平均分配：1000 页分 4 段各 250 页，800 页分 3 段，1027 页分为 257、257、257、256 页。每段结束保存 part-*.md，全部完成后统一生成一个 EPUB。最终 content.md 含完整文字和图片引用。

## 继续与重试

可以停止后重新选择同一份 PDF，点击“开始／继续转换”，已完成页面无需重新 OCR。重新启动 App 或更换输出文件夹也能复用。正常使用只需启动一次，程序自动处理全部分段；需校对页面直接跳过，不会要求人工确认或反复重试。

界面会显示原 PDF 总页数、各段页码范围、总进度、每段进度、已复用页数和需校对页数。识别时显示正在处理的一个或两个分段、原 PDF 页码及各页耗时；双分段并行及自动降级原因也在界面显示。段状态包括等待、处理中、完成及完成但需校对。

PDF 内容改变后会建立新的缓存，不会误用旧文字。缓存保存在 `~/Library/Application Support/BookWeave/cache`，任务结果文件夹内的“任务状态.json”记录相应位置、已完成页数、分段范围及待校对页。

2.3 使用新的高清清边缓存，与旧版低清输入分开保存。升级后首次转换会重新识别；之后仍可断点继续，旧版结果文件不覆盖。

## 清边与高清识别

扫描页会抽查跨页重复的边缘小图形，清理确认的装饰条，再裁去多余空白，使用最高 300 DPI 的页面输入识别小字。极大页面的长边最多 5000 像素，以限制内存。正文、图注和页码不按固定比例裁切；不能确认的图形保留。

边饰检查在独立进程中运行，最多等待 60 秒；异常时保留不确定图形并继续，原因写入报告。报告记录清理页数和装饰数量。处理后的页面参考图会进入 EPUB，原始 PDF 不修改。仅出现一次或与正文相连的装饰，可能无法自动清除。

## 速度与资源

同一任务只加载一个 PaddleOCR-VL-1.6 官方 GGUF 模型。文字版页面直接提取；扫描页交给模型。一个独立进程准备页面，预备队列最多两页。只有超过 300 页、内存至少 12 GB 且当前可用内存至少 25% 时，才开启两个不同分段的并行识别；同一段内部仍按页顺序处理。两个任务共享模型，不复制两份模型。高清输入会增加首次识别时间和缓存空间；EPUB 参考图长边最多 1800 像素，识别文字和参考图一起保留。

识别采用流式输出，发现明显的超长字符重复或循环段落会提前停止该页。单页识别总时限为 90 秒；页面准备最多等待 60 秒。异常识别页保留原图、标记原 PDF 物理页码并继续下一页；准备进程超时则终止并重新建立进程，未能提取原图时如实写入异常报告。当前一组分段结束后释放识别引擎，下一组自动继续。每页独立计时、独立关闭识别连接，单页超时不会关闭另一页的连接。

并行过程中每秒检查资源：可用内存低于 15%、识别引擎内存超过物理内存四分之一（最多 4 GB）、交换空间增长超过 256 MB，或识别引擎占整机 CPU 持续 5 次采样超过 75%，停止增加并行任务；当前页面结束后，剩余工作自动改为单任务，本次不再升回并行。资源读数不可用时也使用单任务。极低内存（不足 10%）或引擎严重超限会立即停止当前共享引擎，受影响页面保留原图并列入校对清单，之后单任务继续。

## 转换中文档与最终校验

页面完成后立即写入缓存，各段完成保存 part-*.md。不同分段可能先后完成；“转换中.md”持续按原 PDF 页序写入已经连续完成的部分，后面分段的结果会等前面页码齐全再合并，最终 EPUB 仍保持原书顺序；异常位置注明“需校对：PDF 第 N 页”。这里的页码从原 PDF 封面第 1 页开始，不是书中印刷页码或阅读器重新排版后的页码。

全部分段结束后自动生成 EPUB，校验页面记录、汇总页序、图片引用及顺序、文件完整性和正文结构。校验通过才显示转换完成。结果包含“转换报告.md”“转换报告.json”和“需校对页面.txt”，列出异常类型、原 PDF 页码及是否保留原图。自动结构校验不等于 OCR 文字准确率校验。

## 图片与已知限制

普通嵌入图片保留，页边位置的小面积、多页重复装饰会过滤；扫描页保留清边后的页面参考图，复杂矢量图页保留页面图。文字可编辑，图片位于对应页文字之后，不保证原 PDF 的图文穿插位置。空白页保留空白页标记。

当前为整页 OCR，未集成完整版面分析流水线；复杂多栏、表格及密集小字需要人工校对。需校对页面清单在结果文件夹内。保存了原图不等于该页文字已经识别准确。
